**Spec:** ../specs/2026-09-29-webrag-design.md

## Global constraints
- No credentials in source; paid calls require OPENAI_API_KEY.
- Website text is untrusted; URLs and quoted evidence must validate against retrieved chunks.
- Report measured results and unverified requirements separately.

- Redirects into private IP space must be blocked.
- Reingestion must not destroy the old index on crawl failure.
- Unknown questions and injection must not receive invented answers.
- Cached replies must report zero new API cost.
- API provider failures must produce stable safe errors.
